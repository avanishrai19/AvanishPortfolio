# AvanishPortfolio

A modern, responsive personal portfolio website built with **React.js** and **Vite** to showcase my skills, projects, education, certifications, and journey as a Full Stack Developer.

* Modern and responsive portfolio design
* Clean component-based React architecture
* Responsive navigation bar
* Hero section with personal introduction
* About Me section
* Skills and technologies section
* Projects showcase
* Education section
* Certifications section
* Resume section
* Contact section
* Responsive design for desktop, tablet, and mobile

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/avanishrai19/AvanishPortfolio.git
```

### 2. Open the project

```bash
cd AvanishPortfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The project will be available at:

```text
http://localhost:5173
```
